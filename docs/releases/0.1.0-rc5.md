# joy-cli-platform 0.1.0-rc5

```roc
app [main!] { pf: platform "{{PLATFORM_URL}}" }
```

Built and tested with Roc
[`0.1.0-rc1`](https://github.com/roc-lang/roc/commit/15177e91f62cafddf5336c455e00e9f05427ac16).

## What changed

- The bundle is a third smaller: 9.9 MB to download instead of 14.9 MB, and
  38 MB unpacked instead of 60 MB. The macOS hosts and musl's libc and
  libunwind no longer carry debug data.
