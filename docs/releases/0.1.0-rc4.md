# joy-cli-platform 0.1.0-rc4

```roc
app [main!] { pf: platform "{{PLATFORM_URL}}" }
```

Built and tested with Roc
[`22e3718`](https://github.com/roc-lang/roc/commit/22e3718d45380cb1cd36df3a8fc3f2b6a49c703b).

## What changed

- An app runs from its source on macOS again, as with `roc app.roc`. With
  0.1.0-rc3 only `roc build` linked: the link stub for libSystem did not list
  what Roc's own dev and interpreter runtimes import.
