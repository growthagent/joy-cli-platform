# joy-cli-platform 0.1.0-rc3

```roc
app [main!] { pf: platform "{{PLATFORM_URL}}" }
```

Built and tested with Roc
[`165a1ba`](https://github.com/roc-lang/roc/commit/165a1baad4971048167702feedbca344ca93ecfc).

## What changed

- `main!` takes `List(OsStr)`. It took the raw form of each argument before.
- A handler that waits on a backend through `Http.send!` stops waiting once
  the request it answers is given up. A proxy no longer runs out of handlers
  behind slow pages a browser has left.
- macOS watches each tree with one recursive FSEvents stream instead of
  kqueue.
- The watcher hashes only regular files, capped while reading, keeps its
  watches when a change to them fails, and watches a folder once it becomes
  readable.
- The server times out a stalled header after 30 s and a stalled body after
  60 s, and caps open connections at 512. A Windows file name that opens
  something else, like a short name or a device, is refused.
- The host links as a static PIE, as Roc requires since
  [roc-lang/roc#12949](https://github.com/roc-lang/roc/pull/12949).
- The repository's tooling is Roc scripts, with no Python.
