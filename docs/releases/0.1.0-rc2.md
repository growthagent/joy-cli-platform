# joy-cli-platform 0.1.0-rc2

```roc
app [main!] { pf: platform "{{PLATFORM_URL}}" }
```

Built and tested with Roc
[`0c440e5`](https://github.com/roc-lang/roc/commit/0c440e5f316f70438af984f2b548da69ab721de9),
like 0.1.0-rc1.

## What changed

- `Server.Config` takes `file_routes`, paths the host answers from roots by
  itself, before any handler runs, so a file never waits behind requests the
  handlers are busy with. A route tries its `roots` in order. With
  `miss: NotFound` it owns its path, and with `miss: AskHandler` what no file
  answers goes to the handler. `download: Bool` answers each file as a
  download.
- Files the host serves get their content type from their extension.
