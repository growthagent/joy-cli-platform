# joy-cli-platform 0.1.0-rc1

```roc
app [main!] { pf: platform "{{PLATFORM_URL}}" }
```

The first release candidate of the platform `./joy` runs on. It targets Linux
(x64 and arm64, musl) and macOS (x64 and arm64). Windows comes in a later
release candidate.

## Roc

Built and tested with Roc
[`0c440e5`](https://github.com/roc-lang/roc/commit/0c440e5f316f70438af984f2b548da69ab721de9).
No nightly has this commit yet, so build the compiler from source at that
commit. `nix develop` in this repository does that.

## What it adds to basic-cli 0.30

- `Server` starts and stops an HTTP server from `main!`, with handlers on
  threads of their own. It answers with a response built in Roc, a file from a
  declared root or an event stream.
- `Events` publishes frames to every open event stream, with a greeting for
  new streams.
- `Sse` builds server-sent event frames.
- `Watch` reports changed files, from inotify on Linux, kqueue on macOS, or by
  polling.
- `Crypt` hashes bytes and files, with `Sha256` and `hash_file!`.
- `Tty` gains `size!`, `is_terminal!` and `is_tty!`.
- `Stdin` gains `bytes_within!`, for reading keys with a timeout.
- `Http.send!` keeps a `Host` header set on the request, as a reverse proxy
  needs.

SQLite, TCP, Unix sockets and locales from basic-cli are left out.
